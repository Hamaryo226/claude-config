# 日本語ドキュメントの書き方

## 文体

- です・ます調ではなく、簡潔な常体で書く (README の説明文は例外的にです・ます調でもよいが、
  1 つのファイル内では必ず統一する)
- 1 文を短く。1 文に主張を 1 つだけ入れる
- 「〜することができます」→「〜できる」のように、冗長な言い回しを削る

## 表記

- 和文と半角英数字の境界には半角スペースを 1 つ置く (例: `Claude Codeを使う` ではなく `Claude Code を使う`)
- 句読点は `、` `。` を使う。`，` `．` は使わない
- 括弧は全角 `（）` ではなく半角 `()` を使い、前後に半角スペースを置く
- コマンド・パス・識別子・ファイル名はバッククォートで囲む
- 数字は半角

## 構造

- 見出しは `#` から始めて 1 段ずつ下げる。段を飛ばさない
- 1 ファイルに `#` (h1) は 1 つだけ
- 箇条書きの記号は `-` に統一する (`*` や `+` は使わない)
- 表は列幅を揃えなくてよい。中身の正しさを優先する
- コードブロックには言語名を付ける (` ```bash `, ` ```csharp `, ` ```ts `)

## 内容

- 既存の README / RELEASE_NOTES の書式と語彙に合わせる。新しい様式を持ち込まない
- 実装を変えたらドキュメントの該当箇所も同じコミットで直す
- 実際に動かして確かめていない手順を、確かめたように書かない
